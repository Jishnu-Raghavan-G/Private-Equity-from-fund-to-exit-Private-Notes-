# Private Equity 360° – Learning Notes & Insights

## About This Repository

This repository contains my personal notes, summaries, key takeaways, diagrams, and reflections while studying Private Equity and the investment ecosystem.

The goal of this project is to build a structured understanding of:

- Private Equity
- Fund Formation
- Fundraising
- Investment Analysis
- Deal Flow
- Term Sheets
- Due Diligence
- Portfolio Management
- Exit Strategies
- Careers in Private Equity

I am documenting my learning journey publicly to improve my understanding and receive feedback from professionals, students, investors, and founders.
